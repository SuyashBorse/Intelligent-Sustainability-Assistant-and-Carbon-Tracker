# Gamification Specification

## Points
Suggested defaults:
- Activity logged: +5
- Challenge completed: +50
- 7-day streak: +30
- Goal achieved: +100

These values should be configurable.

## Challenges
Examples:
- Use public transport twice this week.
- Log activities for 7 consecutive days.
- Reduce transportation emissions by 10%.
- Complete an energy-saving habit.

## Achievements
- First Step
- 7-Day Streak
- Green Traveler
- Energy Saver
- Eco Champion

## Rules
- Do not create financial redemption unless explicitly added.
- Prevent duplicate point awards for the same achievement.
- Store completion state.
- Recalculate progress from trusted data where practical.
